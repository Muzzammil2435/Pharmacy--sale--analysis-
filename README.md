# Pharmacy Sales Analysis - Task 3

## Objective
Analyze pharmacy sales data to identify medicine usage trends and revenue patterns. Evaluate top-selling medicines, monthly sales growth, and compare branded vs generic medicines.

## Dataset
File: pharmacy_sales.csv
- 20 records
- Columns: DATE, MEDICINE, TYPE, QUANTITY, SALE_AMOUNT, MONTH
- Medicines: Paracetamol, Amoxicillin, Metformin, Amlodipine, Albuterol

## Visualizations Planned
1. Top-selling Medicines by Quantity - Bar Chart
2. Monthly Sales Growth - Line Chart  
3. Branded vs Generic Revenue - Pie Chart
4. Revenue by Medicine Type - Bar Chart

## Key Insights Expected
- Paracetamol is top-selling by quantity (Generic, low cost)
- Branded medicines generate higher revenue per unit
- Steady sales growth from Jan to Jul 2024
- Generic medicines have higher volume, Branded have higher profit

## Tools Used
- Python
- Pandas for data analysis
- Matplotlib for visualization

## How to Run
pip install pandas matplotlib
python sales_analysis.py
